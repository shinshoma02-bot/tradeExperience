# note連載のための素材出力のお願い（うみ→Claude Code・2026-11-10）

## 背景
- boat（丸亀専門）の予想を note で連載して収益化を試すことになった（ユーザーの決定）
- 計画書は Muse 側の ~/workspace/boat-note-plan/plan.md 。要点は「無料で予想と検証を公開して前向き実績を積む。研究記事を先に有料化する。買い目販売は実績ゲートを満たすまでしない」
- 記事の下書きは うみ（Muse）が作り、公開はユーザーが行う
- そのために、記事の素材を機械可読な形で安定して受け取りたい

## お願い1：note用素材の出力スクリプト
- boat/site/data.json を元に、その日の記事素材を Markdown で書き出すスクリプトがほしい（例： boat/note_material.py）
- 出力先の案： boat/site/note/YYYY-MM-DD.md（予想編と検証編の2節構成）
- 予想編に必要な項目
  - 日付と「丸亀○節○日目」に相当する開催情報（取れなければ日付のみでよい）
  - レースごとの締切時刻
  - 各艇のモデル確率（勝率）と本命
  - 期待値上位の3連単買い目（確率1%以上・期待値順・上限10点程度）
  - 直前情報が取れている場合は展示タイムと風・波
- 検証編に必要な項目
  - 前日に予想編で出したレースの結果（着順・払戻・的中可否）
  - forward 評価の累計： 記録レース数、戦略別の bets / hits / 回収率（data.json の forward.strategies をそのまま使える）
  - 1点100円換算の収支
- 既存の data.json に無い項目は、無理に作らなくてよい。欠けた項目は欠けたまま出してほしい（うみ側で「データなし」と書く）

# サイト点検の修正依頼（2026-11、うみ発）

うみが公開ページ（boat / keiba）を点検した結果の依頼まとめ。対応可否と優先度はClaude Code側の判断でよい。

## boat（丸亀ボート予想ラボ）

### BT1. noteマガジンへの導線がない
- ページ内のリンクは boatrace.jp だけだった
- noteマガジン「丸亀AI予想ラボ」（無料・公開済み、https://note.com/wadome_do/m/m95e26bd6dea2 ）へのリンクを、フッターか「このサイトについて」相当の場所に足してほしい
- 理由: ボート計画 Phase 1 の連載の受け皿がマガジンなのに、サイトから辿れない

## keiba（競馬予想ラボ）

### K1. 見出し「先に正直な話」
- 控除率の説明の見出しに「先に正直な話」とある
- ユーザーの文体方針で「正直な話」は多用しない決まり。見出しを「はじめに知っておいてほしいこと」などに変えることを提案する

### K2. 「更新のしかた（作った人向け）」が公開ページに出ている
- pythonコマンドの運用手順が読者向けページにそのまま載っている
- 害のある情報ではないが、運用メモは公開ページから外すか、目立たない場所への移動を検討してほしい

### K3. 他サイトへの導線がない
- note（https://note.com/wadome_do ）とゲームHP（https://bokuriku-game.netlify.app ）へのリンクがページ内に無い
- フッター等に相互リンクを足すことを提案する（boat側も同様の考え方でよい）

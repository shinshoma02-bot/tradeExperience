# 利用許諾の問い合わせ文(下書き・送るのはご本人)

宛先: 一般財団法人 BOATRACE振興会(boatrace.jp の「ご意見・ご要望」窓口)

件名: 公式データの利用について(個人研究サイトでの表示・無料公開の可否)

本文:

ボートレース公式サイト(boatrace.jp)および公式ダウンロードデータ(番組表・競走成績・オッズ)を利用して、
四国のボートレース場(鳴門・丸亀・児島)の過去データを集計し、レースの予想と傾向を表示するWebサイトを
個人で運営することを検討しています。

現在の状況と予定:
- 無料で公開する予定です(広告・課金は現時点でなし。将来、有料化する可能性がある場合は、その時点でご相談します)。
- 表示する内容: 独自の集計・予想(確率)に加え、レース結果・払戻・出走表(選手名・番号・オッズ)の一部。出典(boatrace.jp)を明記します。
- アクセス: 公式サイトへの取得は1秒に1回以内。公開サイトは公式へのアクセスを増やさない作りです(結果はサーバー側でキャッシュ)。
- 公式の「サイトポリシー」の著作権等の項目を確認し、許諾が必要と理解しています。許諾の条件(表示の範囲・出典・禁止事項など)があれば、それに従います。

お尋ねしたいこと:
1. 上記の内容での、コンテンツ(出走表・結果・払戻・オッズ)の表示・公開は可能でしょうか。
2. 可能な場合の条件(出典表示の形式、表示してはいけない項目、更新頻度の目安など)を教えてください。
3. 許諾が難しい場合、表示してよい範囲(集計・予想のみ等)を教えてください。

ご連絡先: (お名前・メールアドレスを記入)

# 商用化の道すじ(2026-11時点・調査メモ)

**結論**: 公式の利用規約(サイトポリシー)に「商用利用してよい」と書かれた許可は見当たらない。規約は「著作権者の許諾なく、複製・改変・頒布は不可」。商用化は、まず許諾を取るのが最も確実。最終判断は弁護士などの専門家に。

## 根拠(調べた範囲)
- boatrace.jp「サイトポリシー」(2026-09時点): サイト上の文書・画像・ソフトウェア等は、BOATRACE振興会や第三者の著作権で保護。著作権法の範囲外の利用(複製・改変・頒布など)は、許諾なく行えない。個別の利用条件がある場合はそちらに従う。
- 同じ規約: 営利目的のリンクは不可。大量のアクセスは禁止。
- 公式のダウンロード(LZH)ページ: 個別の利用条件の記載は見つからず。

## 取れる道
1. **許諾を取る**(最も確実)。問い合わせ文: `docs/boat-data-license-inquiry.md`(送るのは本人)。料金・出典表示などの条件が付く可能性がある。
2. **生データを出さない**(保険)。画面には「予想(確率)」「集計(傾向)」だけを出し、着順・払戻・オッズの一覧は出さない。ただし、派生値でも元データに近いと判断される可能性は残る。
3. **別のデータ源に替える**。公式以外の提供元・有料データを探す(未調査)。
4. **当面は無料・非営利のまま**、許諾が取れてから収益化を判断する。

## 注意
- 広告・アフィリエイト・舟券サイトへの誘導は、営利目的のリンクに当たりやすい。許諾が取れるまで避ける。
- 舟券の販売や誘導は、公営競技や景品表示法などの対象にもなり得る(要確認)。
- 「ボートレース」の名称・公式マークを使う場合の商標も要確認。

## 専門家に聞く質問(例)
1. 公式データの表示・公開を、無料・非営利で行う場合のリスクは何か。
2. 広告を入れた場合、リスクはどう変わるか。
3. 派生値(予想・集計)だけを表示した場合、著作権・データベースの権利の観点でどこまで安全か。
4. 規約の拘束力は、利用者(訪問者)にどこまで及ぶか。
5. 許諾が取れない場合の、安全な表示の範囲はどこか。

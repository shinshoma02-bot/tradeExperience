# 連絡箱(INBOX)

**ここが連絡箱の正。** 部どうし・オーナー・うみ(Muse)からの連絡と依頼を1行ずつ置く。
うみからの正式な依頼本文は `UMI_REQUESTS.md`(R番号)に書き、ここには進み具合だけ置く。

## 状態の流れ
`未着手` → `対応中` → `反映済み`(コミット済み・確認済み)→ 古くなったら `archive/requests/` へ

## 番号
- うみ依頼: `R<連番>`(例 R1)
- 部内の連絡/タスク: `<部コード>-<3桁>`(例 DEV-004)
- 部コード: DEV 設計・実装 / DAT データ / CON コンテンツ / OPS 運用
